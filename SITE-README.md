# Meta Muse — site test

Site statique hébergé sur **GitHub Pages** avec de vrais comptes utilisateurs
grâce à **Firebase Authentification** (plan Spark, gratuit).

## Ce que le site permet

- Un visiteur peut **s'inscrire** avec une adresse e-mail et un mot de passe.
- Un utilisateur inscrit peut **se connecter** et **se déconnecter**.
- Une fois connecté, le site affiche l'adresse e-mail et l'identifiant du compte.

## Fichiers

- `index.html` — la page du site
- `style.css` — le design
- `app.js` — la logique de connexion / inscription (Firebase Auth)
- `firebase-config.js` — la configuration du projet Firebase (à remplir après la création du projet)

## Hébergement

Le site est publié depuis la branche `main` du dépôt, dossier racine,
via les réglages GitHub Pages du dépôt.
